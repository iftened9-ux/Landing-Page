A project built as part of [The Odin Project](https://www.theodinproject.com/) curriculum,

## About

A landing page built from scratch, focused on:
- Semantic HTML structure
- Layout with Flexbox / CSS Grid
- Responsive design

## What I practiced

- Structuring a page using sections (header, hero, features, testimonial, footer)
- Positioning and alignment with Flexbox
- Basic styling: colors, typography, spacing
- Organizing CSS code
